# 🎓 Student Placement Prediction and Analysis System

An end-to-end Machine Learning project designed to analyze student academic performance, skills, assessments and predict placement outcomes.

## 🚀 Project Overview

The Student Placement Prediction and Analysis System uses Machine Learning to estimate student placement outcomes based on academic records, technical skills, projects, internships and assessment performance.

## ✨ Key Features

- Student Registration System
- Four Online Assessments:
  - Aptitude
  - Coding
  - Technical
  - Communication
- Automatic Assessment Result Calculation
- AI-Based Placement Prediction
- XGBoost Machine Learning Model
- Prediction Confidence Display
- Interactive Streamlit Dashboard
- Student Performance Analytics

## 🧠 Machine Learning Models

- Logistic Regression
- Random Forest
- XGBoost

## 📊 Project Workflow

Student Data → Data Cleaning → Exploratory Data Analysis → Feature Engineering → Model Training → Model Evaluation → Placement Prediction → Dashboard

## 📝 Assessment Module

Students complete four assessments covering aptitude, coding, technical knowledge and communication skills. Their results are displayed through a final assessment report.

## 🤖 AI Placement Prediction

The system uses a trained Machine Learning pipeline to predict the placement status of students.

The prediction is an estimate and does not guarantee actual placement.
